# Azure 100 Day Cloud Engineering & Security Challenge

> **Building practical Azure engineering skills through 100 hands-on implementation projects.**

This repository documents my **Azure 100 Day Cloud Engineering & Security Challenge**—a structured portfolio of 100 practical Azure implementation projects covering cloud administration, networking, security, identity, governance, automation, monitoring and incident response.

Rather than treating each project as an isolated lab, this challenge follows a progressive roadmap where every implementation builds on previous concepts to create a secure, well-managed Azure environment. Every project is completed using live Azure services and documented with detailed READMEs, architecture diagrams, validation steps and screenshots.

# 📂 Repository Structure

The challenge is organised into individual daily implementation projects.

```text
azure-100-day-challenge/
│
├── Day01-Project-Name/
├── Day02-Project-Name/
├── Day03-Project-Name/
│
├── ...
│
├── Day56-Project-Name/
│
└── Day100-Project-Name/
```

Each project folder follows a consistent documentation standard and typically contains:

```text
DayXX-Project-Name/
│
├── README.md
├── screenshots/
├── dayXX-architecture-diagram.png
└── Supporting files (where applicable)
```

Supporting files may include PowerShell scripts, Azure CLI commands, ARM templates or other implementation resources where relevant.

# 💡 Why I Built This Challenge

Cloud engineering is developed through practical implementation, not just studying documentation or completing individual exercises.

The goal of this challenge is to strengthen my Azure engineering skills by designing, deploying, validating and documenting real-world administration and security scenarios while building a portfolio that demonstrates practical experience across Microsoft's cloud platform.

Every project is an opportunity to understand not only **how** Azure services are configured, but also **why** they are used and **how** they work together within secure, well-governed cloud environments.
